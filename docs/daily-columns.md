# Daily AllRanks columns

On each run of the AllRanks midnight scheduler, follow these steps after syncing the automation checkout to main and reviewing ranking changes, before validation and deployment.

1. Determine today's editorial date in `Asia/Seoul`. Inspect both `data/columns/YYYY-MM-DD.json` and `data/columns/YYYY-MM-DD-2.json`. Each can hold one column for that date. Keep any column with `verified: true` and fill only the remaining slots. Complete earlier drafts when the original sources support them. If both slots already have verified columns, continue through validation and deployment.
2. For each open slot, choose a recently released or materially updated public ranking. Prefer distinct topics or analytical questions for the two daily columns. Inspect recent columns and ranking dates. If the run added no appropriate rankings, choose another recent public ranking. Start with a question the data can answer and an analytical finding worth publishing.
3. Open the original data and methodology. Check every number, rank, unit, time period, population and interpretation against the sources. Recompute differences with source precision, and mark the displayed precision and interpretation limits. Consider an alternative dataset if the original evidence is incomplete.
4. Write an original English column matching the site language and the schema in `src/lib/columns.ts`. Put the main finding in the summary. Use the body to explain the comparison, quantify the finding and show how the methodology affects the conclusion. Include a comparison table where it helps, related public ranking IDs, original source URLs and a dated verification note. Use `verified: true` after direct review. Save any unresolved draft with `verified: false` and report the specific evidence gap.
5. Validate, build, commit, push and deploy through the existing ranking job. After Vercel reports READY, check the production HTML for both column cards above the FAQ and confirm each new URL opens and appears in the archive, RSS feed and sitemap. If deployment fails, leave the committed columns available for the next run to deploy, and report the failure. Include each column URL and source review in the daily report.

The launch agent `world.allranks.daily-local-deploy` runs at midnight on the scheduler Mac. The existing deployment publishes the columns when it completes. Static pages reflect the checkout used for that build.
