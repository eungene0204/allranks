# Daily AllRanks columns

On each run of the AllRanks midnight scheduler, follow these steps after syncing the automation checkout to main and reviewing ranking changes, before validation and deployment.

1. Determine today's editorial date in `Asia/Seoul`. Inspect `data/columns/YYYY-MM-DD.json`. If today's column already has `verified: true`, retain it and continue through validation and deployment. If a previous run left a draft for today, retain and complete its research where possible. One date maps to one file and one published column.
2. Choose a recently released or materially updated public ranking with an unused angle. Inspect recent columns and ranking dates. If the run added no appropriate rankings, choose another recent public ranking. Start with a question the data can answer and an analytical finding worth publishing.
3. Open the original data and methodology. Check every number, rank, unit, time period, population and interpretation against the sources. Recompute differences with source precision, and mark the displayed precision and interpretation limits. Consider an alternative dataset if the original evidence is incomplete.
4. Write an original English column matching the site language and the schema in `src/lib/columns.ts`. Put the main finding in the summary. Use the body to explain the comparison, quantify the finding and show how the methodology affects the conclusion. Include a comparison table where it helps, related public ranking IDs, original source URLs and a dated verification note. Use `verified: true` after direct review. Save any unresolved draft with `verified: false` and report the specific evidence gap.
5. Validate, build, commit, push and deploy through the existing ranking job. After Vercel reports READY, check the production HTML for the new URL and home card above the FAQ, then confirm the URL appears in the columns archive, RSS feed and sitemap. If deployment fails, leave the committed column available for the next run to deploy, and report the failure. Include the column URL and source review in the daily report.

The launch agent `world.allranks.daily-local-deploy` runs at midnight on the scheduler Mac. The existing deployment publishes the column when it completes. Static pages reflect the checkout used for that build.
