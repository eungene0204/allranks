# AdSense Low value content 원인 조사

조사일: 2026-10-23. 대상: https://allranks.world 와 로컬 저장소. 사용자 제공 거절 화면은 사이트 수준 사유만 제공하며 Google 내부 평가 URL·점수는 공개하지 않는다. 아래는 확인된 사실에 근거한 원인 가설이며 실제 판정 원인의 확정이 아니다. 랭킹 데이터·앱 코드·배포는 변경하지 않았다.

## 핵심 판단

가장 가능성이 큰 문제는 공개 원자료를 수천 개의 비슷한 표와 정형 문장으로 재구성한 데 비해, 페이지별로 추가되는 분석·의사결정 지원이 제한적이라는 점이다. 지구본·시각화·연간 추이·국가별 발견은 실제 고유 기능이지만 모든 상세 페이지에서 충분한 추가 가치를 보장하지는 않는다. 자동 수집 또는 통계 사이트라는 이유 자체로 부적격이라는 뜻은 아니다.

## 확인한 사실

로컬 공개 필터와 같은 조건(verified:false 제외, manual/agent는 명시적 true 필요)으로 JSON을 집계했다. 공개 대상 3,401개, 국가 한정 1,657개. 운영 홈/About의 총수와 일치한다.

| 출처 | 공개 랭킹 수 |
| --- | ---: |
| World Bank | 1,627 |
| OpenAlex | 762 |
| OurAirports | 316 |
| GeoNames | 273 |
| 위 네 출처 합계 | 2,978 (87.6%) |

이는 출처 집중 및 반복 제작 구조의 증거이지, 해당 출처 이용 자체가 위반이라는 의미는 아니다. 설명(desc)이 30단어 미만인 자료 1,902개(55.9%), 항목 5개 이하인 자료 72개. 단어 수·항목 수는 내부 진단 수치이며 Google 승인 최소 기준이 아니다. 전체 본문 길이와도 다르다.

### 1. 높은 우선순위: 원자료에 더하는 고유한 해석 부족

- src/lib/insights.ts의 rankingInsights는 순위표에서 1~3위, 배율, 최댓값·최솟값·중앙값, 지역별 개수를 같은 틀로 계산한다. 별도의 조사·주제별 해석 데이터는 사용하지 않는다.
- https://allranks.world/ranking/gdp-nominal 에서 동일 패턴을 실제 확인했다. GDP의 환율 영향, 명목/실질/PPP 차이, 작은 경제의 해석 같은 질문은 이 상세 페이지의 해설로 해결하기 어렵다.
- src/components/RankingContext.tsx는 정의·단위·범위·출처를 제공한다. 중요한 출처 메타데이터지만 그 자체가 심층 분석은 아니다.
- Google은 출처를 단순 재작성하는 것을 넘어 실질적인 추가 가치와 독창성을 제공하는지 묻는다: https://developers.google.com/search/docs/fundamentals/creating-helpful-content

### 2. 높은 우선순위: 넓은 주제와 반복 페이지 확장

- 국가별 대학 지표, 도시 인구, 활주로 길이 등이 나라별로 분리된다. 예: data/rankings/mk-longest-runways.json 및 https://allranks.world/ranking/mk-longest-runways .
- 인구·경제 지표부터 비누·세제 추천까지 범위가 넓다. 페이지별 독자와 활용 목적을 더 구체적으로 설명할 필요가 있다.
- src/app/sitemap.ts는 공개 필터를 통과한 모든 랭킹을 별도의 콘텐츠 품질 선별 없이 사이트맵에 넣는다. 출처 검증과 페이지의 고유 가치는 별개의 판단이다.
- 대량 제작만으로 스팸이라고 단정할 수 없다. 검색 조작 목적도 확인하지 못했다. 다만 반복적이며 추가 가치가 약한 페이지가 사이트 평가에서 문제가 될 가능성이 크다.

### 3. 높은 우선순위: 제목이 암시하는 범위와 실제 비교 대상

- https://allranks.world/ranking/internet-users 의 제목은 Most Connected Countries이지만 실제 비교 대상은 2025년 값이 저장된 10개국뿐이다. 로컬 JSON과 운영 표에서 모두 확인했다.
- 비교 국가 수와 누락 안내는 존재하지만, 제목·첫 요약의 1위 표현은 세계 전체 최고로 오해되기 쉽다. 최신 연도 값이 없는 국가가 빠진 이유와 세계 전체 상위 10개국 목록이 아니라는 점을 먼저 설명해야 한다.
- 이 조사는 원자료 전체를 재검증하지 않았으므로 수치 오류 또는 빠진 특정 국가의 실제 순위를 단정하지 않는다.

### 4. 중간 우선순위: 제품 추천도 원문 목록 요약에 머묾

- data/rankings/soap.json은 Consumer Reports/Quartz의 제품 6개와 짧은 특징을 담고 있다. 직접 비교가 불가능한 부문별 선정이라는 주의 문구와 출처 검증 메모는 존재한다.
- rankingInsights의 product 분기는 첫 세 항목과 원문 순서·비교 한계를 반복한다. AllRanks가 추가로 수행한 가격 비교·사용 조건별 선택 도움·평가 기준 정리 같은 내용은 해당 데이터/공통 해설에 없다.
- 직접 테스트를 했다고 주장하거나 임의 점수를 추가해 해결해서는 안 된다. 원출처의 선정과 AllRanks의 분석을 구별하고 검증 가능한 비교만 추가해야 한다.

### 5. 중간 우선순위: 운영·편집 책임과 설명의 정확성

- https://allranks.world/about 는 운영 주체를 AllRanks라고만 소개하며 담당자의 배경·전문성·구체적 편집 책임 정보가 제한적이다. 연락 이메일은 이미 있다. 실명 공개가 AdSense의 일률적 필수 조건이라는 뜻은 아니다.
- https://allranks.world/methodology 는 120일 지난 자료 검토를 안내하지만 scripts/freshness.mts는 기본적으로 기준연도가 현재보다 1년 넘게 뒤처진 자료를 나열한다. 다른 운영 절차가 있는지는 확인하지 못했으며 문서와 확인 가능한 구현이 다르다.
- 같은 페이지는 모든 출처의 재사용 허용을 단정하지만 출처표에 라이선스 미표시 항목도 있다. 미표시만으로 무단 사용을 단정할 수 없으나 허용 근거를 명확히 기록해야 한다.
- 모든 페이지에 동일 FAQ 7개와 Prototype v0.3가 붙는다(src/app/layout.tsx, src/components/FooterFaq.tsx). FAQ나 Prototype 문구 자체가 금지된 것은 아니지만 짧은 본문에서는 반복 안내가 크게 보이고 완성도 인상을 약화할 수 있다.

## 이번 조사로 주원인이라고 볼 수 없는 사항

- About, Methodology, Privacy, 연락 이메일은 이미 공개되어 있다. 이 페이지를 단순 추가하는 처방은 현재 상태에 맞지 않는다.
- 운영 robots.txt는 전체 허용이고 sitemap.xml은 HTTP 200이다.
- 상세 페이지에서 Loading ranking…이 먼저 추출됐지만 실제 HTTP 응답에는 표가 포함된다. 대표 상세 3개(soap, wbx-sp-pop-80up-ma, mk-longest-runways)를 직접 요청해 모두 200과 table 태그를 확인했다. 따라서 빈 페이지·JavaScript 전용이라고 단정하지 않는다. 실제 Google 렌더링·크롤링 결과는 별도 도구로 확인해야 한다.
- 트래픽·체류·재방문 수치는 확인하지 않았다. 사용자 관심 부족을 실제 원인으로 단정하거나 임의 최소 방문자 수를 제시할 근거가 없다.
- 데이터가 과거 연도라는 이유만으로 저품질은 아니다. 기준연도와 수집일을 구분하는 현재 설계는 유지할 가치가 있다.

## 권장 개선 순서 (미구현)

1. 인터넷 이용률 같은 좁은 표본의 세계 순위 제목·요약·포함 기준을 먼저 바로잡는다. 데이터 변경 시 원출처 재검증이 필요하다.
2. 핵심 랭킹부터 비교 목적, 계산법, 누락·한계, 전년 변화, 관련 지표와 달라지는 결론을 주제별로 제공한다. 원자료를 실제로 읽고 근거를 연결한다.
3. 비슷한 국내 지표를 국가별 도구나 주제 허브로 묶을지 검토한다. 고유 가치가 부족한 상세는 보강·통합·광고 제외를 우선 판단하고, 필요하면 검색 색인 대상도 조정한다. noindex 또는 사이트맵 제외만으로 AdSense 문제가 해결되지는 않는다.
4. 국가 간 비교, 기준연도 통일, 지표 조합, 내보내기 등 사용자의 질문을 완결하는 기능을 강화한다. 기존 시각화/추이/국가 발견 기능을 발전시킨다.
5. 편집 책임·검토 과정·실제 갱신 규칙·재사용 근거를 정확히 공개한다. FAQ는 페이지 내용에 필요한 위치에 배치한다.
6. 대표 페이지와 반복 페이지를 다시 점검한 뒤 재심사를 요청한다. 글 개수·글자 수·대기 일수의 임의 기준이나 승인 보장은 없다.

## 정책 해석의 범위

Google 검색의 helpful content 가이드는 콘텐츠 평가 보조 기준이며 AdSense의 별도 승인 체크리스트가 아니다. 실제 광고 정책의 low-value / replicated content 조항과 구별해야 한다. 정책 원문 조사는 adsense-policy-research-2026-10-23.md에 기록한다.
