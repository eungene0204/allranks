# AdSense 콘텐츠 품질 개선 구현

2026-10-23. 기존 원인 조사와 크몽의 E-E-A-T 글쓰기 조언을 참고하되 Google 공식 정책과 경험담을 구분했다. 승인 보장이나 임의의 글 개수·단어 수 기준은 적용하지 않았다.

## 구현

- `/guides`와 주제별 해설 9편: 경제 규모/생활 수준, 실질 성장, 인플레이션, 실업, 인터넷 이용률의 표본, 대학 연구 지표, 공항 물리 지표, 도시 인구 경계, 제품 추천 목록 해석.
- 글은 독자의 질문, 답, 해석 근거, 한계, AllRanks의 비교 판단, 관련 자료와 원출처 순서다. 가정한 산술 예제와 실제 관측값을 구분했다. 작성 주체는 AllRanks assistant이며 가상의 전문가·직접 사용 경험을 만들지 않았다.
- GDP 해설에는 동일 연도인 두 실제 저장 표에서 국가별 GDP 총액/1인당 값과 표 내 위치를 연결하는 비교표를 제공한다. 연도가 다르면 표를 생성하지 않는다.
- 주요 상세에는 관련 해설을 연결하고, 동일 국가/출처의 관련 지표를 묶어 제공한다. 공통 템플릿 해설은 계산 결과라고 명시한다.
- 모든 랭킹 상세 앞부분에 포함 항목 수와 수집 방식별 제한을 표시한다. 인터넷 이용률의 화면 제목을 `Internet Use by Country`로 바꾸고 수치상 선두는 포함된 관측값 내 결과라고 한정한다. 원본 JSON·값·순서·검증 상태는 변경하지 않았다.
- 수치 비교가 가능한 상세에 두 항목 선택과 절대 차이를 제공한다. 같은 스냅샷만 사용하고 비율 값의 차이는 percentage points로 표시한다. 순위·이진 값·생활용품 추천에 수치 차이 도구를 노출하지 않는다. 저장값 동률은 기존 표의 이름순 위치이며 공동 순위라는 주장은 하지 않는다.
- OpenAlex·OurAirports·GeoNames는 snapshot year를 실제 단일 관측연도와 구별한다. GeoNames에서는 도시별 인구 시점/경계 차이를 경고한다.
- 공통 FAQ를 전체 레이아웃에서 홈으로 옮겨 반복을 줄였다. 홈·헤더·푸터·사이트맵에서 해설에 접근할 수 있다. Prototype 문구를 제거했다.
- `/editorial-policy`에 AI 관여, 원자료/계산/해석 구분, 검증의 범위, 정정 절차를 공개했다. 방법론의 120일 검토 약속을 실제 freshness 스크립트 동작에 맞췄다. 재사용 권한을 모든 출처에 일괄 보장하던 문구를 수정했다.
- 전역 광고 스크립트를 제거해 검색·빈 상태·실패 화면에서도 광고가 요청되지 않는다. AdSense 계정 메타태그와 ads.txt는 소유권 확인용으로 유지한다. 개인정보처리방침과 편집 정책에 광고 중단 상태를 반영했다. 광고 재개는 별도 구현·동의 처리·게재 범위 검토가 필요하다.
- 미검증 자료 공개 필터는 유지했다. 일괄 삭제·noindex는 하지 않았다. 색인 제외 자체를 저품질 개선으로 간주하지 않는다.

## 출처 대조

각 글의 sources URL을 직접 열어 정의와 설명을 확인했다. World Bank GDP/1인당 GDP/실업/인터넷 API 메타데이터, World Bank 실질 성장 glossary, WHO PPP 설명, BLS CPI 및 노동력 정의, ITU 통계 안내, OpenAlex common attributes/institutions, OurAirports downloads/data dictionary, GeoNames export/readme, Good Housekeeping 테스트 방법 안내를 사용했다. 실제 URL은 `src/lib/reading-guides.ts`와 각 공개 해설의 Sources에 수록한다.

수집 동작 설명은 `scripts/sources/worldbank.mts`, `scripts/regional/airports.mts`, `scripts/regional/geonames.mts`, `scripts/freshness.mts`도 대조했다. 기존 3,401개 랭킹의 모든 관측값을 새로 원출처 검증한 작업은 아니다. 변경되지 않은 자료의 verified 플래그를 새로 올리지 않았다.

## 검증

- `npm run lint`: 성공.
- `npm run data:validate`: 3,405개 파일, 오류 0, 경고 3. 기존 미검증 초안은 비공개 유지.
- `npm run build`: 최초 실행은 설치된 Next.js의 보안 알림으로 중단되었으며, 같은 명령 재실행 후 성공. 의존성은 변경하지 않았다.
- 로컬 production HTTP 확인: 홈/해설/정책/방법론/개인정보/대표 상세/검색/사이트맵 응답, 본문 표·해설·광고 스크립트 부재, 미검증 자료 4개의 404, 사이트맵·클라이언트 카탈로그 제외를 포함한 27개 경로를 확인했다.
- 브라우저 자동화의 iab/chrome 표면은 이 세션에서 사용할 수 없었다. 따라서 실제 브라우저 선택 조작·모바일 시각 검증을 완료했다고 주장하지 않는다.

## 배포 및 남은 운영 작업

이번 작업은 로컬 구현이다. 프로덕션 배포나 AdSense 재심사 신청은 실행하지 않았다. 재심사 전 배포된 버전 확인, 실제 브라우저 UI/모바일 확인, AdSense가 제시하는 상태 확인이 필요하다. 콘텐츠는 핵심 주제부터 보강한 것이며 나머지 세부 지표도 실제 사용자 질문과 출처에 따라 계속 개선해야 한다.
