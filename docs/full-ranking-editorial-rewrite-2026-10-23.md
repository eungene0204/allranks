# 전체 랭킹 해설 재작성

## 범위

공개 대상 3,401개 전체의 상세 본문을 개편했다. 9개 대표 가이드에만 연결하던 기존 구조에서 모든 랭킹에 설명 본문을 렌더링하는 구조로 바꿨다. 미검증 초안 4개는 공개하지 않는다. 원본 값·순서·검증 플래그를 바꾸지 않았다.

E-E-A-T는 공식 승인 점수나 자격 인증이 아니다. 이 구현은 출처, 설명의 범위, 계산 근거와 작성 주체를 보강한다. 3,401편을 각각 독립적인 현장 취재나 전문가 심사로 작성한 것은 아니다. AI 보조로 작성한 지표 유형별 규칙과 각 스냅샷의 실제 관측값을 결합한다. 이 범위를 `/editorial-policy`와 본문 작성자 안내에도 공개한다.

## 출처 작업

- World Bank 공식 indicator API의 전체 메타데이터 29,544개를 직접 받아, 공개 랭킹이 사용하는 1,627개 코드를 모두 대조했다. `data/editorial/worldbank-definitions.json`에 이름·정의·기관·주제·가져온 시점을 저장했다.
- 비 World Bank 원출처 311개 주소를 직접 요청했다. 237개는 HTTP 200으로 응답했고 74개는 오류/접근 제한 등이 있었다. 이 검사는 내용 검증이 아니라 접근 가능성 관찰이다. 데이터셋 기준으로 원출처 응답이 확인된 924개, 접근이 제한된 850개, 공식 메타데이터를 확보한 World Bank 1,627개다.
- 접근이 막힌 자료는 새로 검증했다고 표시하지 않는다. 기존에 공개 가능했던 저장 스냅샷과 출처를 유지하고, 상세의 출처 안내에 접근 제한을 알린다. 기존 검증 플래그를 새로 올리지 않았다.
- 공식 메타데이터에 정의 텍스트가 없는 경우도 별도로 알린다. 메타데이터 레코드가 존재한다는 사실과 상세 정의를 확보했다는 주장을 구분한다.
- SIPRI TIV, WGI, ASA p-value 해석, Epoch 데이터 안내도 원문을 열어 해석 기준을 대조했다. 관련 출처는 적용되는 본문에 직접 연결한다.

## 글의 구조

모든 본문은 다음을 포함한다.

1. 이 지표가 답하는 질문과 정확한 단위·대상·시점
2. 실제 포함 자료에서 계산되는 결과, 동률·분포·코드 집단 등
3. 사용자가 비교 전에 확인할 조건과 활용 방법
4. 수집 시점, 정렬·반올림과 작성 방식
5. 지표 유형과 실제 source.note에 따른 해석 한계
6. 원출처·정의·접근 확인 범위·정정 방법

59개 유형별 설명을 적용한다. 연구 지표 5종, 공항·도시·지역 GDP, 인구, 재고/흐름, 구매력/통화, 가격/물가, 법 제도 평가, 예측, 예/아니오 코드, 순위 목록, p-value, 임금 프리미엄, 표본 크기, 무기 이전 TIV, 컨테이너 TEU 등에서 서로 다른 해석을 제공한다. 성별·연령 집단·가격 기준·비율·건강/배출/식량 공급/용량 등 제목에 명시된 조건을 추가 설명한다.

World Bank 정의는 24단어 이하의 짧은 인용으로 구분하고 원문 전체에 연결한다. 출처의 문장과 자체 해설·계산을 섞어 직접 조사한 경험처럼 보이게 하지 않는다. 독립적인 제품 사용 경험이나 가상의 전문가를 추가하지 않는다.

## 동작과 갱신

- `src/lib/ranking-article.ts`: 실제 데이터와 유형별 해설을 결합하는 본문 작성 함수
- `src/lib/editorial-profiles.ts`, `metric-reading.ts`: 지표 해석과 비교 판단 규칙
- `src/lib/editorial-data.ts`: 서버 전용 메타데이터·출처 관찰 로더
- `RankingReading`: 모든 공개 상세에 본문·출처·정정 안내 렌더링
- `related-readings.ts`: 같은 국가/출처 또는 주제·연도가 맞는 후속 읽기 선정
- `editorial:refresh`: World Bank 정의 갱신. 수치/verified 변경 없음
- `editorial:check`, `editorial:report`: 전체 공개 자료의 본문·출처·정의 누락과 완전 동일 본문 검사
- 빌드 전 전체 해설 검사를 실행해 새 World Bank 코드의 정의가 빠지면 빌드를 막는다.
- 원자료 스냅샷이 바뀌면 값·분포에 관한 본문도 함께 계산되므로 과거 숫자를 고정 문장으로 남기지 않는다.

순위형/이진/자국통화/p-value/제품 부문별 추천에 오해를 줄 수 있는 수치차 도구를 노출하지 않는다. 자국통화·예측·p-value·이진 지표의 첫 요약도 별도로 작성한다. 기존 정형 Highlights는 상세에서 제거해 같은 숫자 설명을 반복하지 않는다.

## 확인 상태

전체 공개 3,401개에 대해 본문·단위·출처·지표별 문맥 누락 및 완전 동일 본문 검사에서 오류가 없었다. 이 검사는 원자료 전수 재검증이나 의미적으로 모든 문장이 완벽하다는 인증이 아니다. 검증 결과는 `data/editorial/coverage.json`에 기록한다. 원래 수동/AI 미검증 초안 4개는 계속 비공개다.

타입 검사와 프로덕션 빌드를 통과했다. 데이터 검증은 3,405개 파일에서 오류 0/기존 경고 3이었다. 59개 해석 유형을 모두 포함한 72개 로컬 HTTP 경로에서 전체 본문·작성 주체·출처/정의 한계·부적절한 비교 도구 제외·미검증 404 및 사이트맵 제외를 확인했다. 배포 추적 파일에 서버 전용 정의·접근 기록 JSON이 포함됨도 확인했다. 첫 빌드는 설치된 Next.js 보안 업데이트 알림으로 중단됐으며 재실행해 성공했다. 브라우저 자동화 표면은 앞선 작업과 동일하게 사용할 수 없어 실제 브라우저 조작·모바일 시각 검증은 완료했다고 주장하지 않는다. 프로덕션 배포와 AdSense 재심사는 이번 작업 범위에서 실행하지 않았다.
